# Support

Use the GitHub Issues tab when this repository is published. The website links are configured in SITE_CONFIG in index.html.

For a bug report, include:

- SketchUp version and full build number
- Windows version
- Dark Mode for SketchUp version
- Steps to reproduce
- Expected and actual behavior
- A screenshot with private project information removed
- Other extensions involved, if relevant

English and Brazilian Portuguese are welcome.

To return to light mode, choose Extensions → Dark Mode for SketchUp → Disable / Light Mode. Use this command before uninstalling to let the extension restore the active model's viewport settings.

Do not include passwords, tokens or private model files in public Issues.
