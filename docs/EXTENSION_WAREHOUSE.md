# Trimble Extension Warehouse listing

## Extension title
Dark Mode for SketchUp

## Summary
A complete dark theme for SketchUp, including menus, toolbars, trays, title bars, tooltips, and the 3D viewport.

## Short description
Dark Mode for SketchUp brings a consistent dark interface to SketchUp on Windows. It styles native Qt menus, toolbars, trays, widgets and tooltips, applies a dark Windows title bar, and optionally darkens the 3D viewport while preserving the model's original viewport settings when saving.

## Compatibility
SketchUp 2024, 2025 and 2026 for Windows.

## Category
Productivity

## Secondary category
Developer Tools

## Support / notes
Some third-party extensions that use their own HTML/WebView or custom native UI may keep their original colors. The extension uses Qt 6 integration specific to current Windows versions of SketchUp.
